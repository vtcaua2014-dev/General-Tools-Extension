06 / GOOD TO KNOW

Questions?
Answered.

Clear answers before you download.

Is General Tools free to use? +

Yes. The extension is available as a free download. Free use does not automatically grant permission to republish, modify, or redistribute proprietary parts of the project.

Does the site install into Chrome automatically? +

No. A normal external website cannot directly install an extension into standard Google Chrome. For Chrome, the store offers a ZIP package and instructions for manual installation.

What about Firefox and custom Chromium? +

Firefox supports website installation of Mozilla-signed XPI extensions, but no signed Firefox build is currently provided. A custom Chromium browser can install directly if its owner implements a trusted native installation integration. Neither option is currently advertised as available without a compatible package.

Can someone view extension code after installing it? +

Yes. Browser extensions run on users' devices, so packaged client-side code may be inspected. License terms and controlled distribution offer protections, but cannot make installed code invisible.

Does General Tools contain third-party components? +

Some elements are based on or incorporate third-party materials. Their original licensing requirements remain in effect. See the applicable notices included with the extension.

INSTALLATION GUIDE

Install on Chrome / Chromium

  1. Download the official extension ZIP from this store.
  2. Extract the ZIP to a folder you can keep on your computer.
  3. Visit chrome://extensions in your browser.
  4. Enable Developer mode.
  5. Click Load unpacked and select the folder containing manifest.json.

Do not delete or move that folder while the extension is installed. Standard Chrome does not support direct installation from this independent website.
