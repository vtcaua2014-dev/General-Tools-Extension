Transparent, static distribution.

Downloads are public files hosted on GitHub Pages over HTTPS, not temporary signed links. Accepting the license in the browser is an acknowledgement, not access control.

Verify the ZIP

Download General Tools v2.0 and compare its SHA-256 hash against SHA256SUMS.txt. The checksum is published alongside the ZIP; it does not independently authenticate the source.

Install in Chromium

Extract the ZIP, open chrome://extensions, enable Developer mode and select Load unpacked. This site does not auto-install extensions.

Security and licensing

This site has no server API or private signing keys. Review the license and third-party notices.
